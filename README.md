# Ubuntu 26.04 Surface AI Workstation

Autoinstall configuration for a Microsoft Surface Pro 9 developer workstation.

## Installer URL

`https://raw.githubusercontent.com/Cardegor/u/main/a`

The installer remains interactive for the normal Ubuntu screens, so disk layout, encryption, Wi-Fi, username and password stay under your control.

## Files

- `a` — Ubuntu 26.04 autoinstall configuration
- `r` — root first-boot bootstrap: Docker, pnpm, Codex CLI and uv
- `f` — first GNOME-login setup: WhiteSur, GNOME extensions, Hermes Agent, VS Code Codex extension and Hindsight helper

## Creative / 3D tooling

Blender is installed from the verified Blender Foundation stable classic Snap channel. FFmpeg and ImageMagick are installed as supporting media tools.

No passwords, API keys, GitHub tokens, OpenAI credentials, Hermes provider keys or other secrets are stored in this public repository.
